Local semantic code search over indexed repositories. For any question about where code lives, how a feature works, or which code to read before editing, call codebase-retrieval FIRST - before Grep, Glob, or reading whole files - and pass the repository root as workspace_full_path. When the file is known but the exact lines are not, use file-retrieval instead of reading the entire file. Linked git worktrees are automatically served from their main repository's index; prefer passing the main checkout path. If a result says the index is warming or still indexing, retry once after a few seconds before falling back to Grep.
