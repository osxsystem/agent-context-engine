Local semantic code search over indexed repositories. For any question about where code lives, how a feature works, or which code to read before editing, call codebase-retrieval FIRST - before Grep, Glob, or reading whole files - and pass the repository root as workspace_full_path. When the file is known but the exact lines are not, use file-retrieval instead of reading the entire file. A linked git worktree is served from the main checkout's index and files. Uncommitted or branch-only edits in the worktree are not visible, and line numbers may differ. Open the worktree copy of any file before you edit it. Pass the main checkout path when you can. If a result says the index is warming or still indexing, retry once after a few seconds before falling back to Grep.
